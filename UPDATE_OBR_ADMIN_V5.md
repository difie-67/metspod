# OBRA v5 — Mini App, админка и OBR

## Что изменилось

- Кнопка «Открыть Mini App» в постоянной клавиатуре теперь сначала выдаёт inline-кнопку. Она открывает Mini App с Telegram `initData`; старый вариант мог открываться без авторизации.
- `/start` нужно отправить один раз после обновления, чтобы Telegram получил новую клавиатуру.
- Завершённая сделка начисляет один раз: покупателю кэшбек в размере `OBR_CASHBACK_PERCENT` от суммы сделки, продавцу — четверть этой награды. По умолчанию `OBR_CASHBACK_PERCENT=5`: при 50 TON это 2500 OBR покупателю и 625 OBR продавцу. Балансы хранятся в SQLite в тысячных долях OBR. OBR — внутренняя бонусная единица без вывода в TON.
- В конце главной страницы появилась секция OBR, баланс также виден в Профиле.
- Администратор может скрывать завершённые сделки из публичного реестра и возвращать их обратно. Запись сделки и on-chain адрес не удаляются.
- В админ-панели появилась витрина OBR: можно добавлять товар, цену и остаток, а также скрывать/включать товар. Пустая витрина показывает «скоро».
- В диагностике остаются code hash контракта, адреса обозревателей и ссылка на TON Verifier; для проверки контракта нужен именно code hash/исходник, а не service wallet.

## Важно при обновлении

Сохраните существующий `DB_PATH` и постоянный Railway volume. Таблицы OBR и колонка реестра создаются автоматически при старте и не требуют ручного удаления базы.

В Railway можно добавить `OBR_CASHBACK_PERCENT=5`. Процент применяется к новым начислениям после завершения сделки; уже начисленные записи не пересчитываются.
