# Изображения для сообщений бота

Положите сюда PNG под указанными именами — бот начнёт автоматически
прикреплять их к сообщениям (`sendNoticeWithPhoto` в `src/bot.ts`).
Если файла нет, ничего не ломается: уходит обычное текстовое сообщение.
Если текст длиннее 1024 символов, фото уходит отдельно, а полный текст следом.

| Имя файла            | К какому сообщению привязано |
|----------------------|-------------------------------|
| `welcome.png`         | Приветствие по `/start` (без deep-link). |
| `deal_created.png`    | «Сделка #N создана»: сколько получит продавец, кто платит комиссию, предмет, ссылка-приглашение. |
| `escrow_ready.png`    | «Сделка #N готова к оплате»: escrow-адрес вычислен (обеим сторонам). |
| `deal_completed.png`  | «Сделка #N завершена» + запрос согласия на публичный @username. |
| `deal_cancelled.png`  | Отмена сделки (до оплаты / до on-chain оплаты / отмена отправлена в блокчейн). |
| `my_deals.png`        | Первое сообщение по кнопке/команде «Мои сделки». |
| `wallet.png`          | Первое сообщение по кнопке/команде «Кошелёк». |
| `help.png`            | Первое сообщение по кнопке/команде «Помощь». |
| `transparency.png`    | Первое сообщение по кнопке/команде «Проверить прозрачность». |
